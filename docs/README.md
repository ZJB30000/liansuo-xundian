## 阅读顺序建议

1. 先看业务挖掘报告，理解问题从哪来；
2. 再看两张流程图，理解流程怎么变；
3. 然后看行业分析，判断方案在行业里是否常见；
4. 最后看设计方案与报价单，理解怎么落地、要多少钱。

## 一致性说明

所有文档中的数字与事实编号（fXX）均来自业务挖掘报告；指标为目标值，不是承诺。涉及自动扣罚、合格结论发布、照片代替复查的内容在全部文档中均被列为禁区。
